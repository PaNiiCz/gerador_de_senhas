# 🔐 Luminous Password Generator

Gerador de senhas fortes com design elegante e efeito de digitação interativo.

![Luminous Password Generator](screenshot.png)

## ✨ Características

- 🎨 Design escuro e sofisticado com efeitos visuais
- ⌨️ Efeito de digitação (typing effect) ao gerar novas senhas
- 📏 Controle de tamanho: 8 a 32 caracteres
- ✅ Opções de caracteres: maiúsculas, minúsculas, números e símbolos
- 📊 Indicador visual de força da senha (Fraca/Média/Forte)
- 📋 Copiar senha para área de transferência com feedback visual
- ⌨️ Atalho de teclado: Enter para gerar nova senha
- 📱 Design responsivo para todos os dispositivos
- ⚡ Slider com debounce para evitar travamentos

## 🚀 Tecnologias

- HTML5
- CSS3 (com animações e transições suaves)
- JavaScript (puro, sem dependências)
